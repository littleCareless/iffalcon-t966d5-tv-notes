## 统一事实口径（更新至 1.69）

- 商品名由所有者提供；系统识别 T966D5 / Android 14。
- Aerial standard 1.69 已成为默认 HOME；重启后无需 Home 即进入 Aerial。
- 待机恢复与 7 路电视输入逐项自检通过；机主确认 HDMI 2 画面正确。
- 曾对 1.46 待机测试出现过一次失败、复测通过的历史；不据单次 1.69 结果推断长期稳定。
- 其他 TCL 机型和固件未验证；18 个包停用试验与 HOME 更换无关。

## 画面规则

- AI 只生成客厅氛围、流程动画、抽象数据流等示意画面；示意镜头加“示意画面”标记。
- 真实电视截图作为锁定的原始素材叠加，不得让生成模型重画、补全或编造屏幕内容。
- 不生成假的 TCL 安装错误对话框、ADB 命令输出、版本页或重启过程。
- 任何截图分享前先遮住账号、会员信息、城市天气、时间、网络地址、二维码和通知内容。
- 不剪掉真实重启中可能出现的厂商桌面；有中间画面就如实呈现。
