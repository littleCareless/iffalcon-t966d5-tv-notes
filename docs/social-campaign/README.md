## 四篇内容的角度

- **抖音视频：** 前后 3 秒见效，突出“安装被拦—找到 TCL 策略—Aerial HOME 成功”的反转。
- **抖音图文：** 一页一个证据点，做成快速扫读的改造流程卡。
- **小红书视频：** 以真实排查日记讲完整经历，解释为什么不能照抄其他 TCL 机型。
- **小红书图文：** 做成可收藏的复现记录，分开列通过、失败和未测试项目。

## 统一事实口径

- 设备商品名是所有者提供的“雷鸟鹤 6 Ultra 2027 款 85 英寸”；系统识别型号为 T966D5，Android 14。
- TCL 的 HOME 安装校验曾拒绝 Aerial。该机通过备份策略、临时为 `app.orchard.tv` 添加单包例外、使用电视的多屏互动安装入口、恢复原策略完成安装。
- 官方 Aerial standard 1.46 成为默认 HOME；一次重启后的首次采样显示 Aerial。CyberUI 仍安装且启用。
- 之后单独进行了 18 个包的可逆停用实验，没有卸载这些包；该实验不是换 HOME 的必要步骤。
- 待机唤醒检查未通过；信号源逐项测试没有执行成功。不能说所有功能均正常，也不能推广为所有 TCL 通用方案。

## 画面规则

- AI 只生成客厅氛围、流程动画、抽象数据流等示意画面；示意镜头加“示意画面”标记。
- 真实电视截图作为锁定的原始素材叠加，不得让生成模型重画、补全或编造屏幕内容。
- 不生成假的 TCL 安装错误对话框、ADB 命令输出、版本页或重启过程。
- 任何截图分享前先遮住账号、会员信息、城市天气、时间、网络地址、二维码和通知内容。
- 不剪掉真实重启中可能出现的厂商桌面；有中间画面就如实呈现。
