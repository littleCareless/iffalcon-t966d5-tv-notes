- FN Video (`com.trim.tv`) version 1.4.2 was installed through the TV's MultiScreen channel and opened to its server setup screen. A NAS account was not entered and playback against the owner's server was not part of the test.

## TVBox configuration

The TVBox client package was `com.github.tvbox.osc.jun`. The owner supplied public source URLs and sources were imported; an import action returned `ok`. Some endpoint checks returned non-JSON content or connection failures, and source availability/playback was not comprehensively verified. Public source lists can change and may include scripts or content without established rights.

Raw source endpoint lists, downloaded responses, EPG/M3U files, and screenshots are deliberately excluded. Recheck any source with its maintainer and only use content you are authorized to access.
